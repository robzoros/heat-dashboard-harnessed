Cómo funciona

Cada jugador y cada bot tiene un color primario y uno secundario. El chip de la izquierda de cada fila muestra el color real que se usa hoy en el dashboard. Si dos entradas comparten primario, la que va después por orden alfabético pasa a usar su secundario: así puedes tener, por ejemplo, todos los bots del mismo color primario sin que se pisen.

Este editor no guarda en el servidor: al terminar, pulsa Descargar y sustituye src/data/player-colors.json en el repositorio (o ejecuta node scripts/player-colors.js set …).

Colores disponibles

Paleta validada para fondos oscuros. Cada color indica cuántas entradas lo usan como primario («N prim.») o como secundario («N sec.»). Pulsa uno para copiar su hex.
